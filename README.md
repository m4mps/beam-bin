# BeamAI Installation Guide

### Arch Linux
```bash
git clone https://github.com
cd beam-bin
makepkg -si
```

### Ubuntu / Debian
```bash
curl -L -o beamai.deb "https://githubusercontent.com" && sudo apt install ./beamai.deb && rm beamai.deb
```

### Fedora
```bash
sudo dnf install "https://githubusercontent.com"
```
